## Egne prosjekter

Prosjektet inneholder Next.js-frontend, Node.js/Express/TypeScript-backend, PostgreSQL-integrasjon og en Expo-mobilapp. Android-appen er klargjort for publisering på Google Play, men er ennå ikke publisert.

**Buddy** – Python-prosjekt for norsk samtale og lagring av samtalehistorikk.

**Chappie** – Eksperimentelt Python-prosjekt med separat runtime, sesjonshåndtering og modelladapter.
